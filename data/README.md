# Источник данных

`solvents.csv` — выборка измеренных химических сдвигов из таблицы [«¹³C solvent shifts»](https://chem.libretexts.org/Ancillary_Materials/Reference/Reference_Tables/Spectroscopic_Reference_Tables/(13C)_solvent_shifts) (Chemistry LibreTexts, OChemOnline). Таблица опубликована по [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). Адаптация в этом каталоге распространяется на тех же условиях.

В выборку включены 38 индивидуальных веществ, для которых есть данные в CDCl₃, C₆D₆ и DMSO-d₆. Исходные строки по отдельным атомным окружениям сгруппированы в списки пиков, перенесены в CSV и дополнены идентификаторами, формулами и SMILES. Поле `table_rows` указывает диапазон строк в текстовом представлении исходной страницы на момент выборки. Его можно сверить по названию вещества, если нумерация страницы меняется. Пики самого дейтерированного растворителя не включены как отдельные референсные записи.

Измерения описаны в [Gottlieb, Kotlyar & Nudelman, J. Org. Chem. 1997, 62, 7512–7515](https://doi.org/10.1021/jo971176v) и [Fulmer et al., Organometallics 2010, 29, 2176–2179](https://doi.org/10.1021/om100106e).

# NMR Structure Ranker

Консольная программа для проверки гипотез о структуре по списку пиков ¹³C ЯМР. На входе химические сдвиги в ppm и, если известна, молекулярная формула. На выходе кандидаты из библиотеки, пары совпавших пиков и сигналы, которым программа не нашла соответствия.

## Попробовать на измеренном спектре

Нужен Python 3.10 или новее. Устанавливать зависимости не требуется.

```bash
python3 nmr_ranker.py rank --peaks '25.72,67.80' --formula C4H8O
```

Это пики тетрагидрофурана в C₆D₆. В справочнике для сравнения используются спектры в CDCl₃. Из двух кандидатов с формулой C₄H₈O программа ставит тетрагидрофуран перед 2-бутаноном и сопоставляет 25,72 с 25,62 ppm и 67,80 с 67,97 ppm. Исходные измерения можно проследить до таблицы по [описанию данных](data/README.md).

Если формула неизвестна, уберите `--formula`. Список пиков можно скопировать из программы обработки ЯМР и вставить в `--peaks`. Сначала уберите остаточные сигналы растворителя и известные примеси, если сравниваете спектр продукта.

## Воспроизвести проверку

```bash
python3 nmr_ranker.py benchmark --query-solvent C6D6
python3 nmr_ranker.py benchmark --query-solvent DMSO-d6
python3 nmr_ranker.py benchmark --query-solvent DMSO-d6 --same-formula
python3 nmr_ranker.py benchmark --query-solvent DMSO-d6 --stress --seed 42
python3 -m unittest discover -s tests -v
```

| Тест | Сопоставление пиков, top-1 | Косинусное сходство гистограмм, top-1 |
| --- | ---: | ---: |
| Измерения в C₆D₆ против справочника в CDCl₃ | 38/38 | 28/38 |
| Измерения в DMSO-d₆ против справочника в CDCl₃ | 33/38 | 27/38 |
| DMSO-d₆, кандидаты с одинаковой формулой | 6/6 | 6/6 |
| DMSO-d₆, стресс-тест с заменой одного пика | 28/38 | 13/38 |

Проверка использует 38 соединений, для каждого есть измерения в трёх средах. Истинная структура входит в справочник, но её измерение из проверяемой среды не участвует в поиске. Стресс-тест искусственно заменяет один пик у каждого спектра, где было хотя бы два сигнала. При равенстве оценок top-1 засчитывается только за единственное первое место. Режим одинаковой формулы включает три пары кандидатов, поэтому по нему пока нельзя судить о качестве на сложных изомерах.

## Как считается оценка

Пики упорядочиваются по ppm. Динамическое программирование минимизирует сумму отклонений в сопоставленных парах и штрафов за пропуски. Каждый пик может участвовать только в одной паре. При стандартном штрафе 2 ppm пара с разницей от 4 ppm оставляется без соответствия. Оценка от 0 до 1 отражает близость списков. Базовый метод для сравнения считает косинусное сходство гистограмм с интервалом 5 ppm.

В своей библиотеке укажи `id,name,formula,smiles,solvent,peaks_ppm` в UTF-8 CSV, один список сигналов на пару ID и растворителя. Сдвиги разделяй точкой с запятой. Передай файл через `--data` и выбери его среду через `--reference-solvent`. Чтобы сравнить несколько своих кандидатов на продукт реакции, нужны измеренные или рассчитанные референсные списки для каждого.

Программа проверяет предложенные структуры по имеющимся референсам. По одному ¹³C-спектру она не строит новую структуру и не подтверждает стереохимию. Если правильного вещества в библиотеке нет, высокий балл сам по себе его наличие не доказывает.

В качестве формата учебной работы использована открытая программа бесплатного [курса Stepik с итоговым проектом](https://stepik.org/course/300891/promo).
